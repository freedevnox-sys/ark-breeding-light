# ARK Breeding Light (Android)

Application Android compagnon pour l'élevage dans **ARK: Survival Ascended** : collection de dinos, lecture des fiches SpyGlass par photo ou capture d'écran, couples conseillés, bébé parfait, minuteurs d'éclosion et de maturation avec les multiplicateurs de ton serveur.

## Installation

1. Télécharge l'APK de la dernière version dans [Releases](../../releases/latest) depuis ton téléphone.
2. Ouvre le fichier et autorise l'installation depuis cette source quand Android le demande.

Android 8 ou plus récent, téléphone 64 bits (ARM). La lecture des photos fonctionne hors ligne une fois l'app installée.

## Mises à jour

L'application vérifie au lancement (et dans **Réglages → Mises à jour**) s'il existe une version plus récente. Elle la télécharge, vérifie son empreinte SHA-256, puis ouvre l'installeur Android : rien n'est installé sans ta confirmation, et ta collection est conservée.

Les informations de version sont dans [`update.json`](update.json).

## Données

Ta collection reste sur ton téléphone. Rien n'est envoyé : la sauvegarde automatique et la synchronisation avec la version PC passent par un dossier que tu choisis (Drive…).
